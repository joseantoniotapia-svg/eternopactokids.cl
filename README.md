# Eterno Pacto Kids

App web de la escuela dominical infantil: clases y libro de clases, cuentos y materiales, Biblia para niños con versiones libres, perfiles familiares con insignias, personajes bíblicos y museo de parábolas.

- `index.html` · la app
- `cuentas.js` · registro, ingreso, congregaciones, roles y conexión con Supabase
- `supabase/schema.sql` · tablas, reglas de seguridad y archivos (pegar en Supabase → SQL Editor)
- `bib/` · Biblias de uso libre: Versión Biblia Libre (CC BY-SA 4.0, © Jonathan Gallagher), La Biblia en Español Sencillo (CC BY 4.0) y Reina-Valera 1909 (dominio público). Fuente: eBible.org.
- `privacidad.html`, `terminos.html` · borradores legales

Sitio estático: se publica en Vercel sin paso de compilación.
